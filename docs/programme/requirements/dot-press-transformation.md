# Dot.Press: complete product transformation and creative presentation experience (R-40)

Owner brief, 2026-11-07, every requirement kept, wording tightened. The working order that came with it: build everything in the brief without stopping, ask for no permission, use the Awwwards skill only for UI/UX and Laravel Boost only for the backend, deploy once everything is done.

## 1. The vision
Dot.Press becomes a presentation platform that breaks from the sameness of PowerPoint, Slides, Canva and generic AI deck generators. People should open it because they enjoy working in it. It combines the joy of creating with the power of professional software, for business, executive reporting, education, sales, marketing, investor pitches and training. It is more intuitive, more enjoyable, more flexible than template tools, more intelligent than basic AI generators, more visually sophisticated than generic SaaS, powerful enough for enterprise and simple enough for a first deck. The advantage comes from thoughtful product design, exceptional interactions, powerful creative tools and a strong engine, not from more buttons.

## 2. Tooling
Awwwards skill only for the frontend and UX (identity, visual design, layout, typography, navigation, interaction, creative workflows, animation, microinteractions, motion, responsive, accessibility, hierarchy, consistency). Laravel Boost only for backend inspection and engineering (architecture, data models, slide and element storage, rendering, document processing, APIs, relationships, jobs, files, collaboration, exports, permissions, auth, performance, security, errors). Keep the stack. Add infrastructure only for a real technical requirement.

## 3. Audit first
Inspect the whole repository before building. Audit pages, creation flows, editor, rendering, templates, element libraries, text editing, images, uploads, animations and transitions, preview, playback, export, import, autosave, collaboration, sharing, permissions, AI, integrations, responsive layouts, database, backend services, tests. Classify every feature: 1 fully functional, 2 functional but needs improvement, 3 partially implemented, 4 visually present but not connected, 5 broken or unreliable, 6 missing but strategically important. Preserve what works. Record what frustrates users and what blocks excellence.

## 4. Research the landscape
PowerPoint, Google Slides, Keynote, Canva, Prezi, Pitch, Gamma, Beautiful.ai, Tome and successors, Visme, Genially, LibreOffice Impress and others. Editing, workflows, engines, animation, collaboration, AI, templates, import and export, strengths, weaknesses, user frustrations. Find gaps. Do not copy interfaces.

## 5. The creative workspace
The editor is a creative workspace, not menus and toolbars. Canvas, slide navigation, contextual controls, element properties, design and layout tools, asset library, structure view, preview and playback, but not the conventional PowerPoint layout. Controls appear when relevant. Selecting text shows typography, size, weight, alignment, colour, spacing, effects, layout. Image: crop, resize, replace, position, transparency, adjustments, masking, layers. Chart: data editing, type, labels, axes, formatting, options. Never show every control at once.

## 6. Make it fun
Smooth drag and drop, fluid movement, alignment guides, smart snapping, responsive resizing, natural manipulation, smooth slide reordering, duplication, dragging between slides, contextual insertion points, quick actions, undo and redo, shortcuts, copy and paste, multi-selection, grouping, layers. Predictable, responsive, clear drop targets. Common actions effortless: add slide, change layout, add image, insert video, create chart, change theme, reorder, duplicate, align, change type, preview, present. Few clicks, sensible defaults, quiet suggestions. Subtle purposeful motion, immediate feedback, subtle confirmation. Never hurt editing performance. Respect reduced motion.

## 7. A limitless canvas
Freeform positioning, resize, rotate, crop, layers, grouping, alignment, distribution, locking, transparency, shape manipulation, multi-select, smart guides, snap to grid, grid visibility, rulers, zoom, canvas navigation. Sizes: 16:9, 4:3, portrait, custom. Change dimensions without destroying layouts, keeping relative positions, with user control.

## 8. Slides and layouts
Blank, pre-designed layouts, section dividers, title, content, image-led, comparison, timeline, data, quote, closing, custom. Add, delete, duplicate, reorder, group into sections, hide, move between presentations, copy and paste, apply layouts, save custom layouts. A layout is a starting point. Consistency help: margins, typography, spacing, colour systems, shared styles, alignment, theme consistency, without making users graphic designers.

## 9. Visual and media library
Images, video, audio, icons, shapes, illustrations, backgrounds, authorised stock integrations, brand assets, reusable assets. Drag onto slides, replace without rebuilding, crop, resize, masks, captions, transparency, layers, reuse across decks. Video and audio play in presentation mode where the format allows. Efficient handling: optimisation, thumbnails, caching, secure storage. Use Dot.Files where it exists and its API supports it.

## 10. Typography and design
Families, sizes, weights, line and letter spacing, alignment, paragraph spacing, lists, text boxes, text fitting, effects, hyperlinks, rich text. Good type pairings and theme presets. Design suggestions for readability and consistency. No automatic formatting that changes user content unexpectedly.

## 11. Data visualisation
Bar, column, line, area, pie, doughnut, scatter, bubble, waterfall, funnel, radar, combination, timelines, geographic where appropriate, tables, KPI. Manual data or imports. Charts update when data changes. Styling, labels, legends, axes, colours, formats, editing, animation, data-source references. No decorative meaningless charts. Link to Dot.Sheets or verified Dot sources where real.

## 12. Intelligent creation
AI assists and never defines the product. Describe a presentation and get structure, outlines, content, layouts, visual and chart suggestions, imagery recommendations, speaker notes. Review and edit the structure before generating. Improve, simplify, professionalise, turn text into a visual, comparison slide, better layout, summarise, improve flow, find inconsistent formatting, find missing information. Whole-deck understanding: repeats, missing context, inconsistent terms, weak flow, overloaded slides, poor hierarchy, unsupported claims, visual opportunities. Generated content is distinguishable from user content. Never silently rewrite.

## 13. Storytelling assistant
Structures: problem, solution, value; summary, findings, recommendations; introduction, evidence, conclusion; opportunity, market, strategy, financials; situation, complication, resolution; training objective, content, application; overview, progress, risks, next steps. Check purpose, progression, evidence, consistent messaging, conclusions, call to action. Suggest, never force.

## 14. Presenting
Full screen, presenter view, speaker notes, navigation, timer, next-slide preview, audience view, keyboard, touch, remote controls where supported, remote sharing where supported. Transitions: fade, push, wipe, reveal, morph-style where technically supported, subtle motion. Element animations: entrance, exit, emphasis, motion paths where supported, sequencing, timing, delay, duration, an approachable sequence editor. Consistent and predictable playback.

## 15. Themes and brand
Colour palettes, type systems, backgrounds, layout presets, image treatments, shape styles, chart styles, shared rules. Apply, create, save, reuse, import brand assets, business brand kits, consistency across decks, organisation-wide kits. A theme applies without destroying custom formatting.

## 16. Templates
Quality over quantity. Business and executive, sales and marketing, finance and investment, education and training, operations and industry (mining, production performance, safety, project updates, engineering, construction, manufacturing). Editable, coherent, excellent.

## 17. Collaboration and workflows
Sharing, team workspaces, role permissions, comments, mentions, review requests, approvals, version history, activity, collaborative editing, ownership, organisation brand assets. Distinguish private, shared, team, public, approved. If real-time exists it must sync reliably and handle conflicts. Never present simulated collaboration as real-time.

## 18. Import, export, compatibility
PPTX import, PPTX export, PDF export, image export, sharing links, other practical formats. Preserve formatting, state limits honestly. Test fonts, images, charts, tables, animations, transitions, dimensions, notes, embedded media. No false claims of full compatibility.

## 19. Dot ecosystem
Investigate real APIs of InfoDot, Dot.Files, Dot.Docs, Dot.Sheets, Dot.Analytics, Dot.Tasks, Dot.Projects, Dot.HR, Dot.Agents, Dot.Notify, Dot.Brain, Dot.Memory. Candidate flows: decks from documents, sheet data to charts, analytics to executive decks, project status decks, decks from approved company information, sharing through Dot.Files, Dot.Agents help, Dot.Tasks follow-ups. Only integrations that real APIs support, with proper auth, tenant isolation, errors, secure exchange. No invented or non-functional connections.

## 20. Performance and backend
Architecture: presentation records, slides, element structure, positioning, layer order, theme, animation data, media references, versions. Editing: autosave, efficient state, optimistic editing, undo and redo, recovery, large decks, efficient rendering, media loading, caching. Reliability: safe background work, export queues, import processing, file validation, transactions, idempotency, error recovery, consistency. Security: tenant isolation, server-side authorisation, secure storage, safe media processing, upload validation, secure sharing, access-controlled exports, protection from malicious files. A failed autosave or export never silently destroys work. Data survives a closed browser where possible.

## 21. A product worth returning to
Beautiful library, recents, favourites, personal workspaces, creation shortcuts, recent themes, reusable assets, templates, smart suggestions, clear organisation, continue where you left off. No gamification, badges, artificial rewards or distracting notifications.

## 22. Mandatory end-to-end acceptance (50 checks)
Creation 1 to 10: blank deck, from template, AI outline, review and edit outline, generate, add, reorder, duplicate, delete slides, sections. Editing 11 to 25: text, typography, images, crop and resize, shapes, tables, charts, chart data, group, layers, themes, change dimensions, undo and redo, shortcuts, autosave and recovery. Presenting 26 to 33: preview, full screen, navigate, transitions, animations, presenter view, notes, playback on supported devices. Collaboration and compatibility 34 to 42: share, permissions, comments, version history, import PPTX, export PPTX, export PDF, verify media and formatting, mobile and tablet. Security and reliability 43 to 50: tenant isolation, unauthorised access, invalid uploads, interrupted autosave, export failure recovery, no silent loss, real integrations, no fake or placeholder features.

## 23. Roadmap
Phase 1 audit. Phase 2 design transformation. Phase 3 creative editing engine. Phase 4 professional presentation capabilities. Phase 5 intelligence and collaboration. Phase 6 production readiness. Stable, enjoyable core editing before breadth.

## 24. Definition of done
Distinctive identity, not generic AI software. Intuitive creation, smooth editing, predictable drag and drop, effortless slide management, accessible design tools, correct charts, reliable playback, working animation and transitions, protected work, import and export within documented limits, collaboration where supported, enforced permissions and tenant isolation, usable mobile and tablet, reliable backend, real end-to-end tests passing.

## 25. Final standard
Not PowerPoint with a different logo, not a Canva clone, not another AI deck generator. Own identity, interaction language and creative experience. Approachable for a beginner, powerful for a professional. "Dot.Press: ideas deserve better presentations."
